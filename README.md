# ReadTrace: 本と映画の記録

本と映画の記録アプリです。実データ検索、ゲストの端末内保存、Google認証後のSupabaseクラウド保存に対応する構成です。Google認証の所有者設定は未完了です。既存の静的HTMLとNodeサーバーを継承し、フロントエンドのインストールやビルドは不要です。実装状況と残作業は `outputs/production-status.md` を参照してください。

## 起動

Node.js 20以降で、リポジトリのルートから実行します。

```powershell
npm start
```

http://127.0.0.1:8011/reading-prototype.html を開いてください。ポートを変更する場合は、PowerShellで `$env:PORT=8012` を設定してから起動します。

## 操作

- Googleログインは実際のSupabaseプロバイダー設定を確認します。Client ID/Secret・リダイレクト設定は所有者設定待ちです。詳細は `outputs/production-status.md` を参照してください。
- 「ゲストで始める」では空の棚から実検索・登録・記録を利用できます。ゲストは端末内保存、Googleログイン後はクラウド保存です。旧データは自動削除せず、ログイン後に取り込む棚を選べます。
- 「デモを試す」から青山しおり・佐々木遥・森健太の棚を開けます。パスワードは不要です。デモ用の新規登録は表示名だけで空の棚を作ります。
- 本／映画タブ、状態フィルター、棚の検索と並べ替えを利用できます。
- 「作品を追加」で実際の書名・著者名・ISBNを検索します。Google Booksを優先し、Open Library・日本語補完にNDL Searchを使用します。Googleの制限は画面に明示します。映画はApple iTunesを検索し、見つからない場合はWikidataの映画情報で補完します。不一致時は検索語を手入力に引き継ぎます。
- 「本を探す」には小説・ビジネス・ミステリー・SF/ファンタジー・歴史・刊行年が新しい本など、APIから取得するセクションがあります。人気順を保証できないデータをランキングとは表示しません。
- 作品を開くと、状態・0.5刻みの評価・任意の感想と日付・ネタバレ・公開範囲を編集できます。完了記録は評価必須です。
- プロフィールと公開棚、フォロー、みんなの記録、いいね、コメント、削除確認、URL共有を操作できます。
- アカウントメニューからデモユーザーの切り替えとログアウトができます。右上のアバターまたはスマホ下部の「自分」から開きます。月間読書目標と実績も利用できます。

UI PocketのApple Books掲載画面を参考に、表紙中心の棚・進行中作品の横並び・スマホ下部の追加ボタンを採用しています。参考と確認内容は `outputs/ui-redesign.md` に記載しています。

本の棚は緑、映画の棚は赤のテーマです。初期表示はグリッドで、表示設定は保存されます。スマホでは表示切り替えから表紙を横にドラッグして選べる立体棚にでき、回転ボタンで表紙を一周回せます。Three.jsを同梱しており、WebGLが利用できない場合は一覧へ戻ります。

## 保存と共有

記録・設定・交流は `readtrace:books-films:v2`、デモログインは `readtrace:demo-session:v2` に保存されます。旧版の保存データは変更しません。

非公開記録は本人以外の一覧・詳細・共有から除外します。公開記録でも閲覧にはデモログインが必要です。共有URLの遷移先はログイン後も維持されます。ネタバレ本文は一覧・共有プレビューに出ず、他ユーザーの詳細では操作するまで表示しません。

Google認証後は `readtrace_records` などのSupabaseテーブルを使用し、本人かログイン済みユーザーの公開記録だけをRLSで取得できます。共有先もGoogle認証が必須です。フォロー・いいね・コメント・目標もクラウド保存します。Realtimeと再読み込みで同期し、クラウド書き込みが失敗した場合にローカル保存を成功扱いすることはありません。ただし、実際のGoogleアカウントによる端末間テストは認証設定後に必要です。

デモユーザーの記録は引き続きブラウザ上のモックです。ゲストは `readtrace:guest:v1` に保存し、共有にはGoogleログイン後の取り込みが必要です。以前の `readtrace:account:<auth-user-id>:v1` を含む元データは残します。デモからGoogleユーザーになりすますことはできません。Google Booksキーなどの秘密情報はEdge Function側だけに保存します。画像を取得できなくてもタイトル入りの代替表示で使えます。

## 確認

```powershell
npm test
```

52件のNodeテストに加え、実Supabaseで15件のRLS/制約検証を実行し、テストデータをロールバックしています。OAuth・クラウドアダプターの単体テストはSDK差し替えで、実際のGoogle認証成功・二端末同期を確認したことにはなりません。実ブラウザの確認内容は `outputs/verification.md` を参照してください。Edge Functionの再デプロイ前は `npm run package:books-function` を実行します。
