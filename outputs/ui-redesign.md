# 棚UIの改修

2026-11-05

## 実際に確認した参考

- [UI Pocket モバイル一覧](https://www.ui-pocket.com/mobile) のブックカテゴリ
- [Apple Booksの掲載画面](https://www.ui-pocket.com/mobile/apps/apple-books/2024-10) の公開範囲、「今すぐ読む」の画面例

進行中の作品と読みたい作品を分ける構成、表紙主体の横並び、少ない主要タブで移動するパターンを参考にした。UI Pocket自体のダークテーマではなく、掲載アプリの使い方を参考にしている。

## 変更

- PCの大きな左サイドバーを上部ナビゲーションへ変更。作品を並べられる幅を確保。
- 本／映画をセグメントで切り替え、読書中・鑑賞中の作品を上部に表示。スマホは横スクロールできる。
- 灰色の表紙枠をなくし、PCで6列、スマホで3列の表紙中心の棚に変更。
- 生成り・明朝見出しを残し、朱色を主要操作、緑を読書状態、金色を評価に使用。
- スマホの追加操作を下部中央へ移動。追加・編集は下から開くシートに変更。
- 各カードから直接記録編集へ移動できる操作を追加。データと保存形式は維持。

## 改修後の確認

- 保存処理の自動テスト14件が成功。
- PCでカード編集・保存、共有URLのコピー通知、別ユーザーからの非公開記録の非表示を確認。
- スマホで下部追加ボタン、検索結果なしから手入力へのタイトル引き継ぎ、シート内の表示を確認。
- キーボードで本／映画のタブ切り替えが動作。
- ネタバレ表示前後、いいねの切り替え、棚内検索と進行中エリアの切り替えを確認。
- 320px幅の文書幅と内容幅はいずれも305px（スクロールバーを除く）。目標表示と進行中見出しの重なりなし。390px・1440pxでも目視確認。
- 最終チェックでJavaScript実行エラーなし（外部画像の読み込み失敗は除外）。
- 共有URLからログアウトし、別のデモユーザーでログインすると元の共有棚へ戻り、公開2作品だけが表示されることを再確認。

改修後のスクリーンショットは `qa/redesign-mobile.png` と `qa/redesign-desktop.png` に保存。

画像取得、認証、共有のモックとしての制約は従来どおり。

## 本と映画の色・スマホの回転表示

本を緑、映画を赤に変更。スマホではThree.jsで厚みのある表紙を描画し、横ドラッグ・前後ボタン・左右キーで作品を選べる。回転ボタンで一周回り、中央の表紙や「記録を見る」から詳細へ進む。一覧切り替えとWebGL失敗時の一覧へのフォールバックを用意。動きを減らす設定では自動回転を抑える。

ローカルで390px幅の表紙上の横ドラッグにより、コンビニ人間から夜は短し歩けよ乙女へ選択が移ることを確認。回転前後のキャンバス領域375×235pxを比較し、背景以外の画素50,735、回転による変化79,225画素を確認。映画テーマと一覧切り替え・詳細への導線も確認。
